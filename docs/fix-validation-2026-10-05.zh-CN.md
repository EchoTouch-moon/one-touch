# 修复交付与验证记录

日期：2026-10-05。基于 a52cae6 的本地修改，尚未提交或部署。对应此前可靠性和布局调整方案；不使用仓库旧截图作为现状依据。

## 已落实

- 交付与查询：后端镜像包含两份运行必需词库；导入前校验文件；考研词库总数与当前用户、搜索、收录筛选保持一致。
- 账号与离线复习：登录及状态接口统一 user_id；缓存、队列按用户隔离；旧会话响应不能更新新账号状态；同步逐条确认删除，保留同步期间新评分，发送原始评分时间，并用 Web Locks 避免多个标签页同时提交。旧队列不猜测账号归属，在设置页提供导出。
- 复习：卡片与评分区共用可用高度；增加显示答案按钮；词典长按释放后保持打开，查词期间关闭拖动评分；输入框和弹窗不触发复习快捷键；返回复习保留进度，空状态、错误状态和待同步状态分别展示。
- 收词：提供可见提交、释义/用法切换及保存按钮；保存词典释义后可以正常完成；建议词确认打开现有词卡，兼容输入法确认；阻止重复保存，手写失败后可重试，连续收词不锁死。
- 草稿：收词与详情页提供继续编辑、保留草稿离开、放弃编辑；路由离开、退出账号和刷新有保护；草稿按账号隔离；IndexedDB 写入/删除串行处理；放弃时取消延迟保存；清空全部手写页前明确确认。
- 布局：统一导航、安全区与页脚占位；账号操作收进菜单；搜索独占主要宽度，保留筛选/页码和返回位置；删除入口降级并确认，失败提示保留；考研列表显示释义及收词入口并刷新状态；手写词典参考改为弹层；支持系统减少动效偏好。

## 已知边界与后续候选

本轮不调整 SRS 算法，不增加新学习功能。服务端事件 ID 去重、多设备迟到评分冲突策略及语料版本化导入仍为后续候选；客户端锁不等于网络请求恰好执行一次。不支持 Web Locks 的浏览器会保留评分并提示同步限制。浏览器存储被清理或设备损坏无法保证本地未同步草稿/评分恢复。
