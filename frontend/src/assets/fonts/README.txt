Bundled webfonts — provenance and licence
==========================================

The three .woff2 files in this directory are unmodified subsets taken from
@fontsource-variable/* v5.3.0 (which repackages the upstream projects).
Only the Latin subset of each family is shipped; CJK resolves to the
platform's own PingFang SC / Noto Sans SC.

  inter-latin-var.woff2            <- @fontsource-variable/inter/files/inter-latin-wght-normal.woff2
  fraunces-latin-var.woff2         <- @fontsource-variable/fraunces/files/fraunces-latin-opsz-normal.woff2
  jetbrains-mono-latin-var.woff2   <- @fontsource-variable/jetbrains-mono/files/jetbrains-mono-latin-wght-normal.woff2
